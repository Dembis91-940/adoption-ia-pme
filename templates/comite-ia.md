# Comité IA — fonctionnement et missions

> **Objet :** organiser la gouvernance de l’IA dans l’entreprise : qui décide, qui contrôle, à quel rythme.
> **Adaptation PME :** pour une petite structure, le « comité » peut être une seule personne (le gérant) assistée d’un référent. L’important n’est pas la taille, c’est la régularité.

## Composition recommandée

| Rôle | Nom | Missions |
|---|---|---|
| **Responsable IA** (pilote) | | Anime le cadre : registre, approbations, audits, formation |
| **Référent données / RGPD** | | Politique de données, conformité, incidents |
| **Référent métier 1** (ex. commercial) | | Voix des usages terrain, retours d’expérience |
| **Référent métier 2** (ex. production) | | Idem |
| **Direction** (validation finale) | | Décisions structurantes, budget, arbitrages |

> *Petite PME (moins de 15 personnes) : responsable IA + direction suffisent. Le comité se réunit alors en mode « point mensuel » de 30 minutes.*

## Missions

1. **Tenir le registre des usages** à jour (registre-usages-ia.md)
2. **Instruire les demandes** d’approbation de nouveaux usages (analyse-risque.md — réponse sous 48 h)
3. **Conduire l’audit mensuel** (audit-mensuel.md)
4. **Traiter les incidents** (fiche-incident-ia.md) et en tirer les leçons
5. **Mettre à jour** la charte, la politique de données, le plan de formation
6. **Veiller** : nouveaux outils, évolutions réglementaires (IA Act, RGPD), retours d’expérience externes (cas PwC…)
7. **Mesurer** les gains de productivité et les risques évités (indicateurs ci-dessous)

## Rythme des réunions

| Réunion | Fréquence | Durée | Contenu |
|---|---|---|---|
| Point comité IA | Mensuel | 30-60 min | Audit mensuel + approbations en attente + incidents |
| Revue annuelle | Annuel | 2 h | Bilan, outils, charte, politique, objectifs |
| Réunion exceptionnelle | À la demande | — | Incident grave, nouveau déploiement majeur |

## Ordre du jour type du point mensuel

1. Registre : nouveaux usages, modifications, écarts (10 min)
2. Incidents du mois : fiches, traitement, leçons (10 min)
3. Demandes d’approbation en attente (10 min)
4. Indicateurs : revue des 5 indicateurs (5 min)
5. Veille et décisions (5 min)

## Les 5 indicateurs de pilotage

| Indicateur | Objectif | Mois M-1 | Mois M | Tendance |
|---|---|---|---|---|
| Usages déclarés dans le registre | 100 % des usages actifs | | | |
| Sorties à risque validées par un humain | 100 % | | | |
| Incidents signalés dans les 24 h | 100 % | | | |
| Temps de traitement d’un incident | < 48 h | | | |
| Écarts constatés en audit | En baisse | | | |

## Règles de fonctionnement

- **Une seule porte d’entrée** : toute demande d’usage passe par le comité (ou le responsable IA).
- **Décisions tracées** : chaque décision (autorisé / conditions / refusé) est notée dans le registre.
- **Neutralité** : le comité ne juge pas les personnes, il évalue les usages.
- **Transparence** : les décisions et la charte sont communiquées à toute l’équipe.
