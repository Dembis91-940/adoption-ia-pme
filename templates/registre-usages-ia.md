# Registre des usages IA

> **Objectif :** recenser chaque usage d’IA dans l’entreprise : l’outil, la tâche, les données impliquées, le niveau de risque, le validateur responsable.
> **Règle d’or :** pas de déclaration, pas d’usage autorisé. Toute nouvelle ligne = passage par le processus d’approbation.

## Mode d’emploi

1. Chaque collaborateur déclare ses usages (outil + tâche + fréquence).
2. Le responsable IA classe chaque ligne (risque faible / moyen / élevé) selon la grille `analyse-risque.md`.
3. Un validateur responsable est nommé pour chaque ligne (principe de responsabilité nominative).
4. Le registre est revu à chaque audit mensuel (`audit-mensuel.md`).

## Niveaux de risque (rappel)

| Niveau | Exemples | Contrôle requis |
|---|---|---|
| **Faible** | Brouillon interne, brainstorming, reformulation | Validation simple par l’auteur |
| **Moyen** | Email client, contenu de réseau social, rapport interne | Validation auteur + relecture responsable |
| **Élevé** | Devis, chiffres financiers, contenu juridique, communication officielle | Double validation + vérification indépendante |

## Statuts possibles

- **Autorisé** — usage validé, inscrit au registre, peut être utilisé.
- **Autorisé avec conditions** — usage validé avec restrictions (ex. : pas de données clients, double validation obligatoire).
- **Refusé** — usage interdit, motif noté dans l’analyse de risque.
- **Suspendu** — usage temporairement interdit (incident, non-conformité).
- **Archivé** — usage abandonné, conservé pour la traçabilité.
