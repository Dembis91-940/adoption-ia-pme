# Plan de formation des équipes — IA sans risque

> **Objectif :** installer en 3 sessions les réflexes qui protègent l’entreprise : classer les données, utiliser les bons outils, vérifier les sorties, déclarer les usages, signaler les incidents.
> **Public :** tous les collaborateurs, y compris la direction. **Durée totale : 5 h** sur 3 semaines.

## Les 6 compétences à installer

1. **Classer les données** (publique / interne / sensible) — le réflexe n° 1, en 5 secondes.
2. **Utiliser les bons outils** — outils du registre, comptes professionnels, usages approuvés.
3. **Rédiger un bon prompt** — contexte, rôle, format attendu, contraintes.
4. **Vérifier une sortie d’IA** — faits, chiffres, cohérence, ton.
5. **Déclarer et demander** — registre des usages, processus d’approbation.
6. **Signaler un incident** — fiche d’incident, sans crainte.

| Élément | Détail |

| Objectif | Comprendre le risque et les règles |
| Intervenant | [responsable IA / direction] |
| Date prévue | |
| Lieu / visio | |

**Programme :**

1. Le cas PwC 2026 : ce qui s’est passé, pourquoi ça coûte des millions (20 min)
2. Pourquoi ça nous concerne : les usages IA dans notre entreprise aujourd’hui (15 min)
3. Les 4 garde-fous de validation humaine (30 min)
4. Le classement des données : publique / interne / sensible — atelier pratique (30 min)
5. La charte IA : lecture, questions, signature (15 min)
6. Quiz rapide de vérification (10 min)

**Livrable attendu :** charte signée par chaque participant + premiers usages déclarés au registre.

| Élément | Détail |
|---|---|
| Objectif | Savoir utiliser l’IA et vérifier ses sorties |
| Intervenant | |
| Date prévue | |
| Lieu / visio | |

**Programme :**

1. Rédiger un bon prompt : démonstration et exercices sur des cas réels de l’entreprise (40 min)
2. Vérifier une sortie : les 4 points de contrôle, exercice sur un exemple avec erreur cachée (30 min)
3. Cas pratiques par équipe : email client, devis, publication, analyse (40 min)
4. Bilan et questions (10 min)

**Livrable attendu :** chaque participant produit un exemple réel (prompt + sortie + validation) versé dans le registre.
